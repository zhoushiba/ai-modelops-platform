## 已知限制与风险

| 类别 | 限制 | 影响 | 缓解 |
| --- | --- | --- | --- |
| 训练 | 线程池 + 单机执行，无跨机调度 | 并发高时排队 | 外置 Celery/RQ，或拆独立 worker |
| 训练器 | 仅 CPU 级 TF-IDF / 哈希向量化 | 效果上限有限 | `BaseTrainer` 可替换为深度模型实现 |
| 数据库 | 默认 SQLite，写并发有限 | 多用户高并发场景受限 | 切换 MySQL/PostgreSQL |
| 大数据集 | 版本样本全量入库（`dataset_sample`） | 百万行时写入变慢 | 改为分批入库 / 只存索引，样本落文件 |
| 评测 | 同步执行，长评测会阻塞请求 | 请求超时风险 | 改为异步任务 + 轮询 |
| Prompt A/B | 默认本地抽取式引擎，未配置上游 LLM 时回答质量有限 | 演示性质 | 配置 `UPSTREAM_LLM_*` 接入真实模型 |
| 安全 | 仅管理员单账号，无 RBAC | 无法多人协作隔离 | v1.2 多租户 |
| 产物存储 | 本地磁盘，未做多副本共享 | 多副本部署不可用 | 对象存储 + 共享挂载 |
| 迁移 | `create_all` 不做 schema 演进 | 升级需手工处理 | 接入 Alembic |

## 交接提示

- 后端入口：`backend/app/main.py`；新增业务先写 `services`，再写 `routers`，最后补 `tests`。
- 前端入口：`frontend/src/router/index.ts`；新增页面三件事：`views/*.vue`、`router` 子路由、`api/index.ts` 方法。
- 改动接口后同步更新 `docs/api.md` 与前端 `src/types.ts`，并跑 `npm run typecheck`。
- 提交前检查：`python -m pytest -q`、`npm run typecheck`、`npm run build` 三项全绿。
